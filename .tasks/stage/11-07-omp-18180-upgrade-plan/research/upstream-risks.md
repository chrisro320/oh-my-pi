# Upstream risks: v18.16.0 → v18.18.0, files outside our patch ownership

Scope: every upstream change between tag `v18.16.0` (`650f3a1`) and `v18.18.0` (`b5a6b2f`) that can
break a local invariant and does **not** live in a path owned by `patches/.18.16.0-families/manifest.json`
(`families[].paths`). Ownership changes are the classify-18180 scouts' deliverable; this file only tracks
seams that sit in unowned files (or in owned files where upstream added a *new* mechanism that no family
covers).

Method (read-only; no builds, no omp run, no writes outside this file):
- Index: `~/.cache/omp-plan-18180/18.18.0/nm/@oh-my-pi/pi-coding-agent/CHANGELOG.md` §18.17.0, §18.18.0
  (also `packages/ai/CHANGELOG.md`, `packages/catalog/CHANGELOG.md`, `packages/natives/CHANGELOG.md`).
- Source of truth: the 18.18.0 tarball tree (`…/18.18.0/nm/@oh-my-pi/*`) and the full upstream diff
  (`https://github.com/can1357/oh-my-pi/compare/v18.16.0...v18.18.0.diff`, cited as `diff@<line>` where a
  hunk was read there and the same text was not re-read in the tree).
- Gates: `patches/verify-*.ts` (71 entries in `patches/apply.sh --print-gates`).

Marking: severity **P0** = silently breaks a project invariant (prompt-cache prefix, compaction chain,
Anthropic OAuth credentials, or worker-mode correctness/wallet) — **P1** = removes or renames the seam a
patch/gate sits on, or changes a contract a gate asserts — **P2** = behavioral drift that needs verifying.
`[INFERENCE]` marks a conclusion not directly read from a file.

Baseline facts re-verified for this survey (cheap, and they bound the risk):
- `engines.bun` is still `">=1.4.4"` in all 13 packages (`…/18.18.0/nm/@oh-my-pi/*/package.json`, e.g.
  `pi-coding-agent/package.json:568-570`). No Bun floor change 18.16.0 → 18.18.0.
- No source change at all in the wires we use through the OpenAI-completions / Anthropic-compat lanes:
  there is no diff for `kimi-code`, `deepseek`, `cline-pass`, `workbuddy`, `pixel`, `cpa` provider modules
  (they are catalog-rule routes, not provider files). What moved for them is catalog data (`U31`).
- `pi-coding-agent/src/session/{messages,date-cwd-reminder,session-storage,session-context,sub-sessions,queued-messages,compaction-methods}.ts`
  are byte-unchanged between the tags (grep of the compare diff returned no `diff --git` entry for them).
  The reminder/anchor/journal machinery our 0038/0043/0047/0076/0077/0083/0084/0093 patches extend is
  therefore *not* re-based by upstream; only its consumers changed (`U22`, `U23`).

## 4. Cross-references and open items for the main agent

- **Worker-thread design (`taskex WorkerThreadsDesign`)** is the consumer of U6/U19/U22; **compaction/prefix
  (`taskex CompactionPrefixDesign`)** is the consumer of U1/U2/U13/U16/U27. Neither should re-derive these
  rows; they should take them as inputs.
- **Threads × 0074**: the two designs interact in one place — 0074's `markPerCallContextMessage` disables
  threading (`anthropic.ts:2258-2262`). Keeping that behaviour is what makes "cache boundary" gates stable;
  dropping it (e.g. by moving the context tail out of `messages`) silently moves Anthropic traffic onto
  deltas. This is the single most consequential upstream interaction for our Anthropic OAuth sessions and
  should be decided explicitly in the plan, not inherited.
- **`ovnfs` on this machine**: `[INFERENCE]` whether `ovnfs` is on PATH here (I could not execute `which`),
  but if it is, 18.18.0 renders the new "# Separate checkouts" system-prompt section and offers ovnfs
  checkouts to isolated subagents on first launch. The plan needs one measurement at implementation time
  (`command -v ovnfs`) because it changes both the prefix baseline and subagent isolation behaviour.
- **Retired-capability residue**: `supports-message-threads` and the other new catalog axes are generated;
  any hand edit to `pi-catalog/src/compat/rules.json` (0036/0044/0052/0057/0065/0100 style) must be
  regenerated from KDL, and 0065/0100's KDL sources no longer match upstream (`U31`).
- **Not exercised, deliberately**: no omp run, no builds, no writes to `~/.omp`, `~/.bun`, `agent.db`,
  `models.db`, credentials or caches; all evidence above is file reads of the pristine trees, the compare
  diff, and the gate sources.
