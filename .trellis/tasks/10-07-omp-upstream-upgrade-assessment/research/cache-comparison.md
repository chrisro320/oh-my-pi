## 3. Upstream improvements worth showing (with limitations)

1. **Warmer refresh observability (18.7.0).** `cache_warming_start`/`cache_warming_end` report phase/provider/model, `outcome: hit|miss|error|aborted`, recorded `usage`, and `warmingStopReason`; also written by `--mode json`, settable via `set_cache_warming`. **Limitation:** session/RPC channel only — extensions cannot subscribe (only `cache_warming_decision` is an `on()` hook, `extensions/types.ts:1398-1401`), so it does not replace 0092's `cache_warming_result`; and it exposes no verdict on idle-horizon/parking.
2. **Kept-turn date/cwd reminder preservation (18.7.0, CHANGELOG `#14502`).** The injector no longer clears on a new root and exposes `isDateCwdReminderControl`, so reminders on turns kept by Anthropic native compaction are not removed — fixes a prefix drift after compaction. **Limitation:** still in-memory only; a resume with a date/cwd change rewrites the first user message and drops any prior mid-rollover injections. 0047's persisted anchors remain required.
3. **Bedrock prompt-cache warming + retention honoring (18.4.6, CHANGELOG lines 420/445).** `resolvePromptCacheTier` now clamps `long` → `short` when unsupported and `isReplayable` covers `bedrock-converse-stream` (`cache-warmer.ts:84-118`, `isReplayable`). **Limitation:** unrelated to Anthropic/1h-tier; does not change the 30-min idle cap.
4. **Compaction/thinking prefix fixes (18.7.0).** `#14339` (midnight mid-turn message no longer rewritten), `#14251` (first kept assistant turn keeps thinking after native compaction), `#14247` (V2 remote compaction keeps recent messages). **Limitation:** adjacent to, not a substitute for, 0047/0084; `#14247` is a compaction concern out of this slice.
