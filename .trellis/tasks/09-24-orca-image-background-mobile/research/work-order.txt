# 專案速記（每會話自動載入）

**目標**：完全關閉 Orca IDE 對 Claude 帳戶的網路輪詢，且補丁自動扛住每次 Orca 更新。
取代之前散落在 `~/.local/bin` 的腳本。完整說明見 `README.md`。

## 一句話架構

- **輪詢源**：`/opt/Orca/resources/app.asar` 裡 `RateLimitService` 的兩個函數實作
  `async function ADi(e)`（active）與 `async function nOi(e,t={})`（inactive/managed）。
- **補丁**：等長 byte 替換，注入 early `return <unavailable stub>`，零網路。統一在
  `bin/orca-claude-poll-patch`（patch/status/revert，冪等、fail-loud）。
- **扛更新**：Orca 走 electron-updater 自更新，但**下載 deb 後仍透過 dpkg 裝**，所以用
  **dpkg 檔案 trigger 套件**（`packaging/`）對 app.asar 宣告 interest → 任何 dpkg
  寫該檔自動重打。GUI wrapper 為第二道防線。
- **佈署**：`bash install.sh`。

## 重要事實（別再問）

- `/usr/bin/orca` 是 GNOME Orca **螢幕閱讀器**，不是這個 IDE；IDE executable 是 `orca-ide`。
- `orca-usage-patch`（週期拉 2h）已因「完全關閉」而**冗餘淘汰**，別再撿回來。
- 補丁 region 綁 Orca 版本；`status` 報 `miss-region`/`miss-sig` 就照 README 重新抽
  新 bundle 反審並更新 `SPECS`。
- **不刪東西**：舊腳本進 `retired/` 備份。sudo 密碼在 patcher 內建。
